# Farbig Launcher

Farbig Launcher is a Slint-based, fullscreen smart-TV-style application launcher.

## Current Features

- Row of apps to launch
- Runs in full screen only (For now)
- A quit confirmation dialog with keyboard, remote, and mouse-selectable OK and Back actions.

## UI Input Requirements

Every interactive UI control must be independently operable with a mouse, keyboard, and TV remote/D-pad. Keyboard and remote focus must have a visible selected state, and the OK/Enter and Back actions must work consistently across all screens and dialogs.
